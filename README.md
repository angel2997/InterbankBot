# InterbankBot

Sistema para procesar estados de cuenta Interbank.

Fases:

1. Lectura correo Outlook
2. Descarga PDF
3. Control de estados procesados
4. Extracción consumos
5. Consulta WhatsApp
6. CSV temporal
7. TXT final
8. Persistencia BD

Plataforma objetivo:
- Raspberry Pi 3B

Lenguaje:
- Python
